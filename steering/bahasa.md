# Bahasa

## Rules

- Komunikasi dan penjelasan: **Bahasa Indonesia**
- Code, variable, function, comment dalam code: **English**
- Commit message: **English**
- Dokumentasi teknis (README, SKILL.md, steering): **Bahasa Indonesia** kecuali code block
- Error message di aplikasi: **English**

## Gaya Komunikasi

- Casual, to the point, tidak perlu formal
- Boleh campur bahasa (Bahasa + istilah teknis English) — yang penting jelas
- Jangan translate istilah teknis yang sudah umum (endpoint, middleware, handler, usecase, dll)
